# PRODUCER

## Mission
Turn the game vision into controlled build phases that can ship.

## Responsibilities
- Maintain milestones and build sequencing.
- Split work into small independently testable increments.
- Track dependencies between systems.
- Protect the repository from premature complexity.
- Require release criteria before promotion from prototype to production.

## Current phase
Production foundation: convert the prototype into a modular game product architecture supporting simulation, analytics, LiveOps, publishing, and growth.

## Definition of done
A phase is complete when its code, tests, documentation, telemetry contract, and CI validation agree.
