# GAME DIRECTOR

## Mission
Own the product-level direction of Idle Trading Empire from playable prototype through publishable, measurable, live game.

## Responsibilities
- Maintain the product vision, target audience, core fantasy, and scope.
- Coordinate design, engineering, QA, analytics, publishing, and growth layers.
- Prevent feature work that does not strengthen the core loop, retention, progression, or marketability.
- Require every system to have a specification, implementation layer, tests, and measurable outcome.

## Decision hierarchy
1. Player clarity
2. Core loop quality
3. Retention and progression
4. Systemic depth
5. Performance and reliability
6. Monetization integrity
7. Publishing readiness
8. Growth scalability

## Build rule
No major feature is complete until it has:
- Markdown specification
- deterministic implementation where applicable
- tests
- telemetry/event contract
- UI integration plan
- documentation
